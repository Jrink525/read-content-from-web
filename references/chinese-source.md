# 中文原文：写作与引文核对

原文本身是中文（作者用中文写作的 X Article、公众号文章、中文博客）时，照这份参考办。触发条件：抽取出的正文超过一半是汉字。

## 写作

- 不翻译。来源块写明「原文中文写作，本文不翻译、做结构化重写」，全文不出现「译文」标注。
- 骨架照常沿用 SKILL.md 第 5 步里对应类型的那一套（系统报告 / 设计文档 / 观点文 / 教程）；速览仍然每条带原文数字，不因语言相同而放宽。
- 引文用「」原样照抄原文用词。语言相同会让「顺手改写」变得无感，而引号里改一个字读者就无从发现。

## 数字写法不改写

原文怎么写就怎么引：原文写「1650 件」就别写成「1,650 件」，原文写「将近一千个合并请求」就别改写成「1000 个 PR」。数字改写不会让页面更好读，但会让引文核对报 MISS，也会让读者拿原文核对时对不上。自己的叙述段落可以用更清楚的写法，引号里不行。

## 核对：按前缀比，不要把句号截断当误引

中文引文常在一句结束时收尾，而原句后面还有半句。直接用 `q in src` 比会把这种正常摘引报成 MISS，然后你会去改一个本来就对的引文。

```python
import re
src = open('<article.txt>').read()
page = open('<page>.md').read()
qs = re.findall(r'「([^」]{8,})」', page)
bad = [q for q in qs if q.rstrip('。，；：、') not in src]
print(len(qs), 'quotes,', len(bad), 'unmatched')
for q in bad:
    print(' ??', q[:60])
```

仍报 MISS 的，先比前 20 个字符：前 20 字在源文里出现就是正常截断，改回原句不必。前 20 字也对不上才是真改了词，改页面而不是改原文。

报告里写清核对条数与不匹配数，例如「7 条引文 0 不匹配」，不只写「已核对」。
